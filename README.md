# 🌱 ONG Solidariedade

Projeto acadêmico desenvolvido com o objetivo de criar um site institucional para uma organização não governamental, utilizando conceitos de **HTML5 semântico, acessibilidade, formulários, validação de dados, CSS e JavaScript**.

O projeto foi desenvolvido como atividade prática da faculdade, com o apoio de ferramentas de **Inteligência Artificial** durante o processo de aprendizado, planejamento, revisão e implementação.

---

## 📚 Sobre o projeto

A proposta do trabalho consiste no desenvolvimento de um conjunto de páginas web para uma ONG fictícia, apresentando suas atividades, projetos sociais e formas de participação da comunidade.

O site foi estruturado utilizando HTML5 semântico, buscando manter uma organização clara do conteúdo e favorecer aspectos de acessibilidade e usabilidade.

O projeto possui três páginas principais:

- `index.html` — página inicial e apresentação da ONG;
- `projetos.html` — apresentação das iniciativas e projetos sociais;
- `cadastro.html` — formulário para cadastro de futuros colaboradores.
